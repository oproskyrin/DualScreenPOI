Before you start

  1. After installation and restart, open DualScreen in Applications. Controls are in the menu bar.
  2. Allow Screen Recording to stream video and Accessibility/input access to control the Mac. macOS may ask you to quit and reopen the app after granting access.
  3. Install the Android client separately. For USB, enable USB debugging and approve this Mac on the tablet. For Wi-Fi, put both devices on the same trusted local network and allow local network access if prompted.
  4. Select the tablet in macOS Sound settings to send audio there. Tablet microphone forwarding is off by default and must be enabled explicitly in the client.
  5. App updates are checked from the menu. Installation requires your approval; ending an active session requires confirmation. App-only updates leave drivers and preferences in place. Driver upgrades use a separate installer and administrator approval.

The app follows the preferred language in macOS (English or Russian); other languages fall back to English. To override it, use System Settings → General → Language & Region → Applications, then reopen DualScreen.

Signing: a locally built ad-hoc app or unsigned package is not Apple-notarized. Distribution on another Mac may be blocked by Gatekeeper. Ad-hoc app updates may require granting permissions again; consistent signing identity is needed to preserve TCC grants.

Logs: ~/Library/Logs/DualScreen/host.log. Third-party licenses are inside the app; driver licenses and corresponding sources are in /Library/Application Support/DualScreenAudio and DualScreenMic.
