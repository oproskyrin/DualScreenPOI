Перед началом работы

  1. После установки и перезагрузки откройте DualScreen в папке «Программы». Управление находится в строке меню.
  2. Разрешите запись экрана для трансляции и универсальный доступ/управление вводом для управления Mac. После выдачи разрешений macOS может попросить закрыть и снова открыть приложение.
  3. Установите Android-клиент отдельно. Для USB включите отладку по USB и подтвердите доверие этому Mac на планшете. Для Wi-Fi подключите оба устройства к одной доверенной локальной сети и разрешите доступ к локальной сети, если появится запрос.
  4. Чтобы направить звук на планшет, выберите его в настройках звука macOS. Передача микрофона планшета по умолчанию выключена — её нужно явно включить в клиенте.
  5. Проверка обновлений доступна в меню. Установка требует вашего подтверждения, а завершение активного сеанса — отдельного согласия. Обновления приложения сохраняют драйверы и настройки. Обновления драйверов устанавливаются отдельным установщиком с подтверждением администратора.

Приложение использует предпочтительный язык macOS — русский или английский. Для остальных языков используется английский. Для выбора языка только приложения откройте «Системные настройки» → «Основные» → «Язык и регион» → «Приложения», затем перезапустите DualScreen.

Подпись: локальная сборка с подписью ad-hoc или неподписанный пакет не нотарифицированы Apple. На другом Mac запуск может быть заблокирован Gatekeeper. После обновления ad-hoc приложения разрешения могут потребоваться снова; для сохранения разрешений TCC нужна постоянная личность подписи.

Журнал: ~/Library/Logs/DualScreen/host.log. Лицензии сторонних компонентов находятся внутри приложения; лицензии и соответствующие исходники драйверов — в /Library/Application Support/DualScreenAudio и DualScreenMic.
